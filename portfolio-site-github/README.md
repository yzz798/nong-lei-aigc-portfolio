# Personal Portfolio Site

这是 Nong Lei 的暗色系静态个人作品集网站，适合展示 AIGC 视频创作、电影开头、短视频剪辑和轻量 AI 应用 Demo。

## 使用方式

直接打开 `index.html` 即可查看网站。

## 推荐替换内容

- `index.html` 中的个人介绍与联系方式
- `script.js` 中每个项目的职责、工具和亮点
- `assets/` 里的作品封面图
- `videos/` 里的本地视频文件
- 联系区的 B 站、网盘或个人主页链接
- 后续可补充每个重点作品的分镜、剧本、提示词和创作过程截图
